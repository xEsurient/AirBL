Keep your AirVPN connection on clean, fast servers

AirBL scans AirVPN servers, checks their exit IPs against the DroneBL blocklist, speed-tests them through a verified WireGuard tunnel, and keeps Gluetun and your WireGuard configs on the good ones.

AirBL dashboard

Every server gets a clear status

A server only counts as clean when every exit IP was checked and found unlisted. A failed lookup is never treated as clean.

Clean

Every exit IP was verified as not listed on DroneBL. Only clean servers are used for Gluetun and generated configs.

Blocked

At least one exit IP is listed. The dashboard shows DroneBL's reason, such as an open proxy.

Unverified

A lookup failed, so the result is unknown. AirBL won't pick the server until it's verified.

How it works

Each scan runs these steps for the countries and servers you choose, on a schedule in your own time zone.

STEP 1

Scan

Looks up each server's exit IPs through AirVPN's DNS (IPv4 and IPv6) and pings entry and exit IPs over ICMP and TCP.

STEP 2

Check

Checks every exit IP against the DroneBL blocklist and marks the server Clean, Blocked or Unverified.

STEP 3

Measure

Speed-tests through its own WireGuard tunnel, after confirming the handshake and that traffic leaves via AirVPN. Servers that stay slow are disabled.

STEP 4

Use

Moves Gluetun to the best clean servers and writes server lists and WireGuard configs for the rest of your setup.

Features

Everything runs in one container with a web dashboard.

DNS-guided endpoints

Exit IPs come from AirVPN's DNS, and each IP is pinged over ICMP and TCP because some hosts block one of them.

DroneBL verification

Every exit IP is checked. Blocked servers show the listing reason; failed lookups stay Unverified.

Verified speedtests

A kill switch and an exit-IP check on every result make sure nothing is measured over your normal connection.

Port & entry discovery

Tests ports 1637, 47107 and 51820 on Entry 1 and 3 over several days and keeps the best combination.

Gluetun control

Switches a local or remote Gluetun through its control API (API key supported) using rules like Clean Only or Top 4, and checks every minute that it stays there.

WireGuard profiles

Generates .conf files per server, the best server per country or city, or just the fastest, plus an always-current wg0.conf.

History & metrics

Scan history, speedtests, ban frequency, disabled servers and port/entry performance, kept in SQLite and charted.

Docker-native

One container with NET_ADMIN. The dashboard stays reachable while tests run, and schedules follow your TZ.

Quick start

Runs on a Raspberry Pi, NAS or any Linux server with Docker.

You need

  • Docker with Compose
  • An AirVPN account and WireGuard .conf files from the AirVPN Config Generator
  • The NET_ADMIN capability (set in the provided compose file)

  1. Add your WireGuard configs

    Put one AirVPN .conf per server you want to scan into docker/conf/.

  2. Set your time zone (optional)

    Create docker/.env with e.g. TZ=Europe/London so schedules like 05:00 use your local time.

  3. Start it

    cd docker && docker compose up -d --build

  4. Open the dashboard

    Go to http://<host>:5665 and choose countries, servers and a schedule under Settings.
