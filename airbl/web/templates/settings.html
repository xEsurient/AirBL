🔍 Port & Entry Discovery

Each scan tests every port × entry combination on one of your top 3 clean servers (rotating), in random order. Combos are compared against each other within the same scan, so different servers and times of day stay comparable. When the period ends, the best combo (at least 3 successful tests) becomes your Preferred Port / Entry. This affects AirBL's own speedtests; Gluetun and WireGuard profiles keep their own port/entry settings.

Enable Discovery

Tests Per Combo

🔗 Gluetun Integration

Automatically generate a servers.json file for Gluetun, containing custom settings per profile such as endpoint routes, speed thresholds, and country filters.

Control Gluetun
After each scan, point Gluetun at the control profile's clean servers via its control server API (PUT /v1/vpn/settings). Needed because Gluetun only reads servers.json at startup. Works for local and remote Gluetun.
Switch Mode
When to move Gluetun to a different server, and which servers it may pick (Top 4 / Best / all clean servers of the control profile)
Control Server Host
Host or IP of the Gluetun control server (local or remote)
Control Server Port
Port of the Gluetun control server (default: 8000)
API Key
Gluetun control server API key, sent as X-API-Key. Required since Gluetun v3.40 unless auth is disabled. The role needs GET /v1/vpn/status, GET /v1/publicip/ip and PUT /v1/vpn/settings.
Control Profile
Which profile's servers are pushed to Gluetun (enabled profiles only)
Connection
Test uses the values above (saved key if the field is empty). Apply pushes the selection now using saved settings.

Alternatively, you can export safe servers directly via API:

Export All Clean Servers:
curl -s http://localhost:5665/api/export/gluetun
Export Clean Servers by Country (e.g., US):
curl -s "http://localhost:5665/api/export/gluetun?country=US"
